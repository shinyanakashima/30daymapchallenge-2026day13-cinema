# 映画を見る、日本を見る。（仮題）

#30DayMapChallenge 2026 Day 5「Senses: Sight」。

全国47都道府県について、過去1年間に「映画館」「映画館以外」で映画を見た人の割合（行動者率）を、同じ尺度の2枚の地図で並べて比べるWebアプリです。

- 問い：映画を見る場所は、地域でどう違う？
- データ：総務省統計局「令和3年社会生活基本調査」調査票A 第93-2表（2021年）
- 構成：Vite + React + TypeScript + SVG。統計は前処理済みJSONを静的配信（APIキー・DB・実行時の外部API呼び出しなし）

## 画面

- PC（幅960px・高さ600px以上）はページをスクロールせず1画面に収まる構成。左に「映画館」「映画館以外」の2地図、右にチケット風カード・凡例・47都道府県の棒グラフ（棒グラフは枠内スクロール）
- 地図は暗い背景に配置。凡例は両地図共通の 0〜100% 固定尺度で、全国値を凡例上に縦線で示す
- 地図・選択リスト・棒グラフのいずれで県を選んでも、両地図とカードが連動する（初期表示：男女計・北海道・全国表示）
- 県を選ぶと、選択県が光り、両地図がその県へズームインして斜めからの視点に切り替わる。「全国を見る」ボタンまたは Esc で全国表示に戻る（視差効果を減らす設定の環境ではアニメーションなし）
- 地図上で行政界にマウスを乗せると、カーソル横に2つの率と全国値との差のミニグラフを表示
- カードには2つの率と、それぞれの全国値（選択中の性別の全国値）との差をポイントで表示
- 性別切替（男女計・男性・女性）。選択県は保持
- 「データについて」「数値表」はフッターのボタンからダイアログで表示（数値表はスクリーンリーダー向けの表としても使用）
- スマホ幅（680px以下）では地図を「映画館／映画館以外」の切替で1枚ずつ表示し、縦にスクロールする構成（尺度・選択県・カードは共通）
- キーボード：地図にフォーカスして矢印キーで都道府県コード順に移動、Home/End で01/47、Esc で全国表示。選択リスト・棒グラフの行・ボタンもキーボードで操作可能
- 読み込み失敗時はエラーメッセージを表示

### 地図の表示上の扱い

- メルカトル図法、全県同一縮尺
- 沖縄県は位置を移動して日本海側の別枠に表示（縮尺は本土と同じ）。画面上に「沖縄県（位置を移動）」と明記
- 小笠原諸島・沖ノ鳥島・南鳥島など北緯30度以南の東京都の島は表示範囲外として省略（画面の出典欄に明記）

## 指標の読み方

- 行動者率＝10歳以上人口のうち、過去1年間（2020年10月20日〜2021年10月19日）に該当する活動をした人の割合（%）
- 「映画館以外」は調査項目「映画館以外での映画鑑賞（テレビ・DVD・パソコンなど）」。配信サービスや一般の動画視聴と同じ意味ではない
- 2項目は排他的でなく、両方で見た人を含む。足し合わせたり構成比として扱ったりしない
- コロナ禍を含む期間の値。年齢構成等の調整はしていない。全国値との差は統計的有意性を示すものではない
- 全国値は公表された全国行の値（47都道府県の単純平均ではない）

## データ生成

```bash
npm install
npm run build:data   # Excel → JSON / CSV / manifest を生成
npm run verify       # 検証（結果は data/verification.md）
```

| ファイル | 内容 |
| --- | --- |
| `data/raw/r3_shakai_A_table93-2_000032223421.xlsx` | 原典Excel（e-Stat statInfId=000032223421、2026-11-04取得） |
| `scripts/build-data.mjs` | 見出し行の項目コード（`04_映画館での映画鑑賞`／`05_映画館以外での映画鑑賞…`）と「推定人口」「サンプルサイズ」を照合して列を特定し、全432行を抽出 |
| `data/processed/cinema_2021.csv` | 正規化CSV（48地域×3性別×3地区区分＝432行、人口集中地区別を含む） |
| `public/data/cinema_2021.json` | 配信用JSON（地区区分＝総数のみ、144件） |
| `data/manifest.json` | 出典・表番号・statInfId・DB表示ID・URL・取得日・対象期間・列対応・件数・利用条件・SHA-256 |
| `scripts/verify-data.mjs` / `data/verification.md` | 検証スクリプトと結果 |
| `public/data/japan_pref.topojson` | 都道府県境界（下記） |

レコード項目：`year, prefectureCode, prefectureName, sex, district, cinemaRate, outsideCinemaRate, sampleSize, estimatedPopulationThousands, missingReason, sourceRow`

- `prefectureCode` は2桁文字列（`00`＝全国は地図に結合しない）
- `sex`：`total`（0_総数）／`male`（1_男）／`female`（2_女）
- `district`：`total`（0_総数）／`did`（1_人口集中地区）／`non_did`（2_人口集中地区以外）
- 割合は 0〜100 の数値。原表の記号は 0 に置換せず `null` とし、`missingReason` に記号を残す（2021年表93-2の映画2指標には該当なし）
- `sampleSize` は回答者数で、映画を見た人数ではない。率にサンプル数を掛けても推定人数にはならない
- `estimatedPopulationThousands` は千人単位

## 出典・利用条件

- 統計：総務省統計局「令和3年社会生活基本調査」調査票Aに基づく結果 生活行動編（地域）趣味・娯楽 第93-2表「男女,趣味・娯楽の種類別行動者率(10歳以上)－全国，都道府県」（2022年8月31日公表）
  - 掲載ページ：https://www.e-stat.go.jp/stat-search/files?stat_infid=000032223421
  - DB表示（統計表表示ID 0003456573）：https://www.e-stat.go.jp/dbview?sid=0003456573
  - 利用条件：[e-Stat 利用規約](https://www.e-stat.go.jp/terms-of-use)（政府標準利用規約準拠、CC BY 4.0 互換）。本リポジトリのデータは原典を加工して作成
- 地図：[dataofjapan/land](https://github.com/dataofjapan/land) の `japan.geojson`（地球地図日本〔国土地理院〕のShapefileを変換したもの）を mapshaper で簡素化し TopoJSON 化。出典：地球地図日本（国土地理院）。配布元の条件に従い、営利目的で利用する場合は著作権者への利用報告が必要
- 参考：[2021年結果の概要](https://www.stat.go.jp/data/shakai/2021/pdf/gaiyoua.pdf)、[調査票A 用語解説](https://www.stat.go.jp/data/shakai/2021/pdf/kaisetsua.pdf)
