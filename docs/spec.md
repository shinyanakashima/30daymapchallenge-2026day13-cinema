Day5 Senses: Sightの実装指示書。更新：2026年11月4日。題材は映画鑑賞に決定。全国47都道府県について、「映画館での映画鑑賞」と「映画館以外での映画鑑賞」の行動者率を比較する。以下の画面・技術案を初期仕様とし、実装担当へ引き継げる形でまとめる。

# 作品の問いと方向性

問いは「映画を見る場所は、地域でどう違う？」。仮タイトルは「映画を見る、日本を見る。」。対象は日本全国。主役は見るという行動の地域差であり、映画ロケ地や映画館POIの検索アプリにはしない。タイトル・リポジトリ名は未確定。

1画面で、2つの地図を同じ尺度・同じ位置関係で比較する。映画館の暗い客席・スクリーン・チケットを連想するデザイン案を使い、文字と数値は読みやすくする。長い物語や必須チュートリアルは設けず、短い補足で理解できる構成とする。

# 指標の意味

対象は2021年10月20日現在で10歳以上の人。過去1年間は2020年10月20日〜2021年10月19日。行動者率は、その属性の人口に占める、期間内に該当する活動をした人の割合（％）。調査日の1日だけの行動、視聴分数、鑑賞本数、映画館入場者数、売上ではない。

使う項目は 04_映画館での映画鑑賞 と 05_映画館以外での映画鑑賞（テレビ・DVD・パソコンなど）。画面ラベルも「映画館」「映画館以外」を基本とし、後者を「自宅」「配信」「Netflix」等だけに置き換えない。YouTube利用や一般の動画視聴も、この項目の意味と同一ではない。

両方で鑑賞した人が含まれる。2項目は排他的でなく、円グラフ・100％積み上げで構成比にしない。両方を見る人・どちらも見ない人・映画を見た人全体の割合は、この2つの周辺集計だけでは求められない。『映画館派／自宅派』『映画好きランキング』とも断定しない。

2020〜2021年のコロナ禍を含む観測結果として年と期間を明示する。地域差から好み、感染対策、映画館へのアクセス、所得等の原因を断定しない。年齢構成等を調整した値ではない。差があることと、統計的に有意な差があることも区別する。

# Excelの実査結果と前処理

2026年11月4日に主Excelを取得し、OOXMLのセル値とヘッダーを確認した。全国＋47都道府県、男女計・男性・女性、地域全体・人口集中地区・人口集中地区以外の組合せで432行ある。主仕様で使う『地域全体』について、48地域×3性別×2映画指標の288値はすべて数値であり、欠損・非公表文字はなかった。人口集中地区別の映画指標全件の数値監査は別途行う。

このファイルの列はA=男女、B=地域区分、C=人口集中地区・人口集中地区以外、D=推定人口（千人）、I=映画館での映画鑑賞（％）、J=映画館以外での映画鑑賞（％）、AO=サンプルサイズ。映画の見出しは7行目、データは10行目から。更新時は列位置を盲信せず見出し・項目コードも照合する。

性別は0_総数／1_男／2_女、地域は00_全国／01_北海道〜47_沖縄県、地区区分は0_総数／1_人口集中地区／2_人口集中地区以外。MVPではC=0_総数だけを使う。地域コードは2桁文字列で保持し、全国00は地図のポリゴンへ結合しない。割合にサンプル数を単純に掛けても公表の推定人数にはならない。

検算値（男女計・地域全体）：全国=映画館29.8％／映画館以外52.7％、北海道=23.3％／51.7％。北海道の男性=23.5％／53.4％、女性=23.2％／50.2％。全国値は公表された全国行から取得し、47都道府県の単純平均で代用しない。サンプルサイズは映画を見た人数ではない。

人口集中地区別の北海道参考値（男女計）：地区内=映画館24.6％／映画館以外52.7％、地区外=17.8％／47.4％。これは北海道内の回答者の居住地区区分であり、鑑賞した映画館の立地を表さない。地区内外をそのまま都市／農村と呼ばない。

再現用スクリプトで元Excel→正規化CSVまたはJSONを生成する。レコードはyear, prefectureCode, prefectureName, sex, district, cinemaRate, outsideCinemaRate, sampleSize, estimatedPopulationThousandsを基本とし、割合は29.8のように0〜100の数値で保存する。小数の浮動小数誤差は表示時に小数1桁へ丸め、欠損はnullと理由で保持する。元の記号をゼロへ置き換えない。

出典manifestに統計名、表番号、statInfId、DB表示ID、原ファイルURL、取得日時、対象期間、列対応、レコード数、利用条件、ファイルのハッシュを保存する。元ファイルと生成手順を追えるREADMEを用意する。取得した原典と作成データをライセンス確認の上でリポジトリへ同梱する。前処理はNode.jsやDuckDB等、作業環境に合わせて選択し、Python必須にはしない。

# 画面と操作

PCは左に『映画館』、右に『映画館以外』の日本地図。共通凡例・共通の固定尺度を使い、片方だけ自動で色の範囲を変えない。初期案は0〜100％の連続尺度。地域差が小さく読めない場合でも、尺度を隠してコントラストを誇張せず、比較グラフを併用する。地図は軽量なSVG都道府県地図を第一候補にし、複雑な背景地図は必須にしない。

県を選ぶと両地図で同じ県が強調され、下部または側面のチケット風カードに、2つの率・それぞれの全国値との差（ポイント）・期間を表示する。全国値との差は、選択中の性別と地区区分をそろえて計算する。主表示の小数は1桁。『割合』と『差のポイント』を区別する。

性別切替は男女計・男性・女性。選択県を保って切り替える。初期表示は男女計で、北海道を選択した状態を初期案とする。県名検索か選択リストを併設し、地図上の小さな県を押せなくても操作できるようにする。

比較の補助として、都道府県ごとに2本の独立した棒を並べるか、横軸映画館率・縦軸映画館以外率の散布図を用意する。散布図は追加機能としMVPに必須にしない。2つの率の差を計算する場合も『映画館派の割合』と呼ばない。

スマホは1画面内で地図を上下に置くか、映画館／映画館以外の切替を使う。共通尺度・選択県・比較カードは保つ。タブレットとスマホで文字や凡例を縮め過ぎない。初回説明は『過去1年間に映画を見た人の割合。両方で見た人も含みます』の短文を常設する。

映画の雰囲気は暗い背景、明るい地図面、控えめなチケットの切り取り線などで伝える。映画ポスターや作品スチルを装飾として無断利用しない。写真・生成画像や複数章の物語は必須にしない。キーボード選択、フォーカス、スクリーンリーダー用の数値表、十分なコントラストを備える。

# 実装構成と地図データ

初期推奨はVite＋React＋TypeScript＋SVG。必要に応じてd3-geo等でGeoJSONから描画する。統計は前処理済みJSONを静的配信し、APIキー・DB・実行時AIは不要。地図投影と地理の正確さを保ち、島や沖縄の位置を別枠にする場合は明示する。

都道府県境界はオープンデータから取得し、コード01〜47で結合する。元境界の出典・利用条件を記載し、全47コードの一対一結合を検証する。2014年等の市区町村名から推測して県コードを作る処理は不要。公開用には適度に簡略化したGeoJSONまたはTopoJSONを使う。

既存のMLIT-LINKS-kankou-receiptは都道府県地図・比較表示・Vite＋React＋TypeScriptの再利用候補。[リポジトリ](https://github.com/shinyanakashima/MLIT-LINKS-kankou-receipt)。再利用する場合はコードと境界データの利用条件を確認し、旅行消費の単位・集計処理を映画統計へ混ぜない。本作品の主データはLINKSではない。

# 年比較と発展機能

MVPは2021年のみ。2016年の対応表は表86-2（男女,趣味・娯楽の種類別行動者率(10歳以上)－全国，都道府県）で、2021年の表93-2と番号が異なる。[2016年の公式表一覧](https://www.e-stat.go.jp/stat-search/files?cycle=0\&layout=datalist\&tclass=000001083768)。全国の映画館率は2016年39.6％→2021年29.8％、映画館以外は52.1％→52.7％と公式概要で比較されている。

2016年比較は任意の第2段階。原表・設問・対象・区分・符号の対応と全47県の欠損を検証してから追加する。差は2021−2016のポイント差で示す。同じ人を追跡した結果ではなく、配信が映画館を置き換えた等の因果解釈をしない。2026年調査結果は2027年9月から順次公表予定のため、今回2026年値を生成しない。[公式公表予定](https://www.stat.go.jp/info/guide/public/shakai/261001.html)

人口集中地区内外の切替、平均行動日数（2021年表93-3）、映画館施設分布との比較は発展候補。平均行動日数は行動者について頻度階級から算出された日数であり、全人口平均でも本数でもない。映画館施設を追加する場合は施設データの年と粒度を合わせる。未検証の発展機能は公開画面に実装済みとして出さない。
